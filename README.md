# ITBox Search Engine

Консольный поисковый движок для локального набора текстовых документов. Проект
читает настройки из `config.json`, строит многопоточный инвертированный индекс,
обрабатывает запросы из `requests.json`, рассчитывает относительную релевантность
документов и записывает результат в `answers.json`.

## Возможности

- загрузка конфигурации и запросов из JSON;
- проверка версии конфигурационного файла;
- сохранение `docid` даже при отсутствии одного из файлов;
- параллельная индексация документов;
- подсчёт частоты слов в каждом документе;
- исключение повторяющихся слов запроса;
- сортировка выдачи по релевантности и `docid`;
- ограничение выдачи параметром `max_responses`;
- автоматические модульные тесты Google Test.

## Стек

- C++17;
- CMake 3.16+;
- nlohmann/json;
- Google Test;
- стандартная библиотека потоков C++.

## Сборка и запуск

Выполните команды из корня проекта:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/search_engine
```

При первой конфигурации CMake автоматически загрузит `nlohmann/json` и
Google Test, если эти библиотеки не установлены в системе, поэтому потребуется
доступ к интернету. Переменные среды задавать не нужно.

После выполнения рядом с `config.json` будет создан файл `answers.json`.

## Запуск тестов

```bash
ctest --test-dir build --output-on-failure
```

## Формат входных файлов

В `config.json` задаются название, версия `0.1`, максимальное количество
ответов и пути к документам. Относительные пути считаются от директории файла
`config.json`.

```json
{
    "config": {
        "name": "ITBoxSearchEngine",
        "version": "0.1",
        "max_responses": 5
    },
    "files": ["resources/file001.txt"]
}
```

В `requests.json` находится массив поисковых запросов:

```json
{
    "requests": ["search engine", "cplusplus development"]
}
```

Каждый документ, содержащий хотя бы одно уникальное слово запроса, попадает в
кандидаты. Абсолютная релевантность равна сумме частот найденных слов, а
относительная — отношению абсолютной релевантности к максимальному значению в
текущей выдаче.

```text
resources/            демонстрационные текстовые документы
```
